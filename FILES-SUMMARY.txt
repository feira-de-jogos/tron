================================================================================
  🚀 COMO USAR
================================================================================

OPÇÃO 1: Acessibilidade rápida (no jogo TRON)
─────────────────────────────────────────────
1. Abra o jogo TRON (index.html)
2. Abra o Console (F12)
3. Execute: toggleAccessibility()
4. Pronto! Sons viram legendas

OPÇÃO 2: Transmitir para espectadores
─────────────────────────────────────
Host (computador do jogador):
  1. Console (F12)
  2. Execute: connectAsHost()
  3. Jogue normalmente

Espectador (outro computador):
  1. Console (F12)
  2. Execute: connectAsSpectator()
  3. Execute: toggleAccessibility()
  4. Veja a partida com legendas!

OPÇÃO 3: Testar com página dedicada
────────────────────────────────────
1. Abra test-page.html no navegador
2. Use os botões para conectar/testar
3. Simule eventos com um clique
4. Veja os logs em tempo real

OPÇÃO 4: Executar testes automatizados
──────────────────────────────────────
1. Console do navegador (F12)
2. Execute: TestSuite.interactive()
3. Execute: TestSuite.runAll()
4. Veja todos os testes passando

================================================================================
  🔌 BROKERS MQTT SUPORTADOS
================================================================================

Padrão (já configurado):
  URL: mqtt.eclipseprojects.io:9001
  Tipo: Público, sem autenticação
  Recomendação: Perfeito para teste

Outros públicos:
  1. HiveMQ: wss://broker.hivemq.com:8884
  2. EMQX: wss://broker.emqx.io:8883

Local (para desenvolvimento):
  1. Mosquitto: docker run -p 9001:9001 eclipse-mosquitto
  2. EMQX: docker run -p 8084:8084 emqx/emqx

Customizar:
  connectAsHost("wss://seu-broker.com:8883")

================================================================================
  🧪 EXEMPLOS DE CÓDIGO
================================================================================

// Ativar acessibilidade
toggleAccessibility()

// Conectar como host (transmissor)
connectAsHost()

// Conectar como espectador
connectAsSpectator()

// Transmitir evento de laser
GameTransmission.onLaserFired("Player1", {x: 100, y: 200})

// Transmitir derrota
GameTransmission.onPlayerDefeated("Player1", "Enemy")

// Transmitir vitória
GameTransmission.onVictory("Player1")

// Ver status
GameTransmission.getStatus()

// Adicionar evento manual
Accessibility.addSoundEvent("laser", "Descrição custom")

// Rodar testes
TestSuite.runAll()

// Ver testes disponíveis
TestSuite.interactive()
